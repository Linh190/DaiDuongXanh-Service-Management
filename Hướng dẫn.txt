============================================================
BƯỚC 1: CÀI ĐẶT CƠ SỞ DỮ LIỆU
============================================================

1.1  Mở SQL Server Management Studio (SSMS)
     Kết nối vào server (mặc định: LAPTOP-0FBIHDMS\SQLEXPRESS
     hoặc tên máy tính của bạn\SQLEXPRESS)

1.2  Chạy file script TẠO CSDL (chạy TRƯỚC):
     File: QuanLyDichVu_DaiDuongXanh_CreateDB.sql
     → Chuột phải vào file → Open with SSMS → nhấn F5 (Execute)
     Script này tạo database, toàn bộ bảng, ràng buộc và trigger.

1.3  Chạy file script NHẬP DỮ LIỆU MẪU (chạy SAU bước 1.2):
     File: 4016_VuNgocLinh_THNN_insertdata.sql
     → Chuột phải → Open with SSMS → nhấn F5 (Execute)

     Sau khi chạy xong, kiểm tra kết quả ở cuối màn hình.
     Số dòng đúng cần có:

       Bảng                 | Số dòng
       ---------------------|--------
       KhachHang            |  52
       NhanVien             |  50
       TaiKhoan             | 152
       NhomDichVu           |   7
       DichVu               |  23
       DonDichVu            |  55
       ChiTietDonDichVu     | ~120+
       HoaDon               |  40
       ChungTu              | ~30+
       LichSuTrangThaiDon   | ~20+

     Nếu có lỗi "Cannot insert duplicate key" → database đã có dữ liệu,
     cần DROP và tạo lại từ bước 1.2.


============================================================
BƯỚC 2: CẤU HÌNH KẾT NỐI TRONG ỨNG DỤNG
============================================================

2.1  Mở file: 03_VuNgocLinh\App.config
     Tìm dòng connectionStrings và sửa Data Source thành
     tên máy chủ SQL Server của bạn. Ví dụ:

     <connectionStrings>
       <add name="QuanLyDichVu"
            connectionString="Data Source=TEN_MAY\SQLEXPRESS;
            Initial Catalog=QuanLyDichVu_DaiDuongXanh;
            Integrated Security=True;
            MultipleActiveResultSets=True;
            Connect Timeout=30;" />
     </connectionStrings>

     → Thay TEN_MAY bằng tên máy tính của bạn
       (xem tên máy: nhấn Windows + Pause/Break hoặc gõ "hostname"
        trong Command Prompt)

2.2  Nếu dùng SQL Authentication thay vì Windows Authentication:
     Thêm: User ID=sa;Password=MatKhauCuaBan;
     Bỏ: Integrated Security=True;

2.3  Cũng có thể cấu hình ngay trong ứng dụng sau khi chạy:
     Vào menu Hệ thống → Cấu hình kết nối CSDL (FrmKetNoiCSDL)
     Nhập thông tin server và nhấn "Kiểm tra kết nối" trước khi lưu.


============================================================
BƯỚC 3: MỞ VÀ CHẠY PROJECT
============================================================

3.1  Mở Visual Studio 2022
     File → Open → Project/Solution
     Chọn file: 03_VuNgocLinh\03_VuNgocLinh.sln

3.2  Build project:
     Nhấn Ctrl + Shift + B  (hoặc Build → Build Solution)
     Đảm bảo không có lỗi đỏ ở cửa sổ Error List.

3.3  Chạy ứng dụng:
     Nhấn F5 (hoặc nút ▶ Start)
     Cửa sổ đăng nhập (FrmLogin) sẽ hiện ra.
